# Cursor: проверка sitemap.xml в staging

- Дата: 2026-09-24
- Ветка: `codex/cursor-canonical`, исходный HEAD `3df7ccf7ff14decba57cefbb1ef121699db04116`
- Статус: локальный этап. Без push, merge, deploy.

Producer сравнивает скачанный `sitemap.xml` со списком `sitemapPaths`. Этот список обязателен: если его нет, запуск отклоняется до старта дочернего процесса. Fixture CLI передаёт пути из `sitemapEntries`. Fixture-сервер публикует в карте только эти адреса, но по-прежнему отдаёт обе HTML-страницы товара с несколькими брендами.

Проверка находит пропущенный, лишний и повторный URL, чужой origin и попадание `/product/...` в карту сайта. Порядок XML-элементов не важен. Разбор XML проверяет корень `urlset`, вложенность `url`/`loc`, ровно один непустой `loc` у каждого `url` и отсутствие хвоста после документа. `image:loc` не считается адресом страницы. Внешние XML-сущности и чужие адреса не загружаются. Отчёт: `meta/sitemap-verification.json`. Код отказа: `sitemap_verification_failed`. `dist/site` не меняется. Проверка HTML остаётся на месте.

Не входит в этап: все внутренние ссылки, настоящий `next build`/`next start`, перенос staging в `dist/site`.
