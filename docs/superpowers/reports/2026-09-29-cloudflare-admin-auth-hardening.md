# Локальное усиление admin-auth прототипа — 29.09.2026

Закрыты три отложенных пункта из [предыдущего отчёта](2026-09-28-cloudflare-local-admin-auth.md), без изменения production:

- Legacy Next adapter при отсутствующем `ADMIN_SESSION_SECRET` снова возвращает `null` при проверке cookie. Секрет не выводится; доступ остаётся закрытым. Создание новой сессии по-прежнему требует корректный секрет.
- Тест совместимости сессий проверяет независимый эталонный токен, рассчитанный из формата до выделения общего codec. Простого сравнения двух нынешних адаптеров для такой гарантии было недостаточно.
- Ключ ограничения попыток входа в Worker теперь строится как HMAC-SHA256 от области `login` и доверенного IP, а не SHA-256 от склеенных строк. Ожидаемое значение закреплено независимым тестовым вектором. Браузерные `X-Forwarded-For` не влияют на ключ.
