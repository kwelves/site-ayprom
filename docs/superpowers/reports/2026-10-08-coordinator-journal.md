# Журнал шагов публикации: локально проверенная точка, 2026-10-08

Журнал теперь может сохранять сведения о прежнем выпуске каталога и прежнем
Cloudflare deployment — конкретном переключении версии сайта. Добавлены записи
о начале и подтверждении готовности, активации, переключения каталога, проверки
сайта, подтверждения очереди и компенсации. Компенсация означает согласованный
возврат сайта и каталога к прежнему выпуску.

Это формат надёжной истории для будущего coordinator, а не уже подключённая
публикация. Coordinator — внешняя программа Node, управляющая порядком всех
переключений. Она должна сохранять намерение до действия и проверять фактическое
состояние после неизвестного ответа. Этот блок сам не выполняет такие действия.

## Границы

Новые этапы требуют оба поля предыдущего состояния, корректную контрольную сумму,
безопасный номер редакции и отличающуюся версию сайта. Старые записи staging
совместимы. Повреждённая история остаётся неизменной, дописывание запрещается.
Ограничения размера, количества записей, записи на диск и блокировки сохранены.

Проверка формата не доказывает правильный порядок действий или реальное состояние
Cloudflare. Следующий coordinator должен сверять всю историю, текущие id
переключений, каталог и очередь при каждом возобновлении. Старую запись
published без новых сведений нельзя считать достаточным доказательством
завершённой согласованной публикации.

В этом блоке SQL и сайт не менялись. Последний настоящий изолированный SQL/HTTP
gate предыдущей точки: 130 SQL, 28 публичных HTTP, 14 capture / 2 гонки,
14 control / 3 проверки конкуренции, 5 queue-state HTTP с потерянным ответом.
Полная закреплённая сборка и браузер прошли в точке control; они не повторялись
для расширения формата журнала.
