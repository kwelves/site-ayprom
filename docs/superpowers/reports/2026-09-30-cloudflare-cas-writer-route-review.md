# Локальная приёмка CAS writer и защиты маршрутов админки

Работа велась в `codex/cloudflare-integration`, отдельно от `main`. Два коммита агентов приняты локально: Claude `2c4e69c` → `7b8aaaa`, Cursor `c1e117d` → `8464fe4`. Push, deploy, DNS, Vercel, production Supabase и R2 не менялись.

## Что действительно проверено

- Writer Claude остаётся внутренним и **не подключён** к `worker.ts` или API смены пароля. Он делает INSERT для пустой `admin_credentials` и условный PATCH по `session_version` для существующей строки. Ключ передаётся только в заголовках.
- Codex добавил RED→GREEN для сбоя часов: раньше исключение callback или невалидный timestamp выходили как сырая ошибка. Теперь выдаётся фиксированный `backend_unavailable` до любого backend-запроса. Три новых теста сначала падали, затем прошли.
- Собственный временный Supabase на `127.0.0.1:56421`, настоящий локальный workerd и PostgREST подтвердили: пустая строка версии 1; INSERT 1→2; повторный INSERT → `conflict`; PATCH 2→3; устаревший PATCH → `conflict`; из двух одновременных PATCH версии 3 прошёл ровно один, итоговая версия 4. Команда: `node scripts/cloudflare/local-credential-writer-postgrest-smoke.mjs`. Итог: `ok:true`, 9 проверок, `cleanup:true`.
- Тест Cursor запустил настоящий локальный workerd с fixture-оболочкой. Без сессии скрытый HTML не отдан через прямые пути к файлам, варианты кодировки/регистра, двойные слеши, HEAD или POST. Маркер оболочки проверяется в ответе; отдельный контроль подтверждает, что его появление тест обнаружит.
- Совместные целевые тесты после cherry-pick: 77/77. `npm run check`: 175 файлов прошли, 1 пропущен; 1556 тестов прошли, 4 пропущены. `npm run build`: прошёл в диагностическом статическом режиме с локальной общей Supabase только на чтение; переменные переданы процессу, `.env.local` не создавался.

## Границы результата

Это проверка локального Worker и отдельной локальной БД. Изолированный стек остановлен и удалён; общий стек не перезапускался. Writer не проверяет текущий пароль, Origin/CSRF и формат/создание PBKDF2 hash, не пишет audit log и не предоставляет пользователю смену пароля. Поэтому ADM-04 остаётся `TODO`. Маршрутный тест не доказывает поведение удалённого Cloudflare. Проверка локального workerd не измеряет Worker Free CPU.

`productionReady` не повышается; Vercel остаётся rollback-origin. Следующие реальные gates: полный admin mutation workflow, media/R2, revision/snapshot/rollback, свежий deployable public build и отдельный разрешённый remote staging.
