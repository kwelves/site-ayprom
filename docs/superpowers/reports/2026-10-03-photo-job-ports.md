# Приватный адаптер очереди фото (2026-10-03)

Статус: **частично готово, только локально**. Ни production Supabase, ни R2, ни Cloudflare не менялись.

`src/cloudflare/media/photo-job-ports.mjs` соединяет внешний Node/Sharp-обработчик с тремя закрытыми RPC Supabase: взять одно задание, подтвердить завершение и вернуть неудачное задание на повтор. Код предназначен для серверного процессора, не для браузера и не для публичного Worker-запроса. Закрытый ключ идёт в `apikey`; старый JWT-ключ дополнительно получает `Authorization`, современный `sb_secret_` — нет. Адрес backend допускает HTTPS либо HTTP только на loopback. Имена RPC фиксированы. Переиспользуется ограниченный HTTP-клиент: 10 секунд, максимум 64 КиБ ответа, запрет redirects. Неисправный ответ или сеть превращается в фиксированную ошибку без текста backend и ключа.

При получении задания адаптер проверяет форму строки, состояние `processing`, токен аренды, ключ исходника и границы размера. При подтверждении передаёт JSON receipt без тел изображений; база остаётся единственной стороной, которая вставляет опубликованное изображение после своей проверки. Для повторной попытки передаётся тот же токен аренды. Адаптер не создаёт заданий и не является admin upload API.
