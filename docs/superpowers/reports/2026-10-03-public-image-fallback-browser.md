# Публичное фото: вариант 404 → master (2026-10-03)

Статус: **частичная локальная браузерная проверка PUB-12**, без production-запросов или изменений сайта.

`node scripts/cloudflare/local-media-fallback-browser-probe.mjs` запускает изолированный Chromium и локальный Vite-сервер. Он рендерит настоящий `ImageFallback` из проекта. Только `next/image` заменён тонкой тестовой границей `<img>`, поэтому это не проверка полного Next runtime или собранной товарной страницы. Внешние сетевые адреса блокируются; изображение берётся из локального JPEG fixture.

Проверены два сетевых отказа в настоящем браузере:

1. URL WebP-варианта отвечает 404, master JPEG отвечает 200. Компонент запрашивает master, декодирует его и показывает без заглушки; `onLoad` срабатывает один раз, `onError` не вызывается.
2. Вариант и master оба отвечают 404. Компонент показывает доступную для ассистивных технологий заглушку «Фотография пока не добавлена»; `onError` срабатывает один раз, готовность изображения не объявляется.

Chromium 151.0.7922.34: оба сценария прошли; page errors отсутствовали. `npm run check`: код 0, 1700 тестов прошли, 4 пропущены, lint/typecheck/colors чистые. Ранее существовавший jsdom-тест проверял те же переходы искусственным `fireEvent.error`; этот probe добавляет реальные HTTP-статусы и загрузку/декодирование в браузере. Chrome DevTools MCP в текущей среде не подключён, поэтому использован Playwright с изолированным профилем. Публичная страница из staging и настоящий R2 в этом тесте не участвуют; до них PUB-12 не повышать до PASS.
