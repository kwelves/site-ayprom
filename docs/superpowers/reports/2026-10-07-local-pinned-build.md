# Локальная сборка из зафиксированного каталога

## Результат

Команда `node scripts/cloudflare/local-catalog-publication-contract.mjs --pinned-build`
подняла отдельную одноразовую Supabase, зафиксировала публичный каталог,
выгрузила его в игнорируемый файл staging, выполнила настоящий `next build`,
обошла страницы через `next start`, проверила HTML, sitemap, ссылки и файлы,
затем собрала диагностический пакет Worker. Изменений на Cloudflare, в DNS,
на Vercel или в production Supabase не было. Общий локальный стек не трогался.

`--local-pinned` в сборщике допускает эту операцию только для изолированного
`http://127.0.0.1:56421`. Приватный ключ и одноразовая возможность чтения
публикации остаются в родительском Node-процессе; дочерний Next получает
только путь к публичному снимку, его SHA-256 и идентификатор выпуска.
Прежний диагностический режим без флага не менялся.

  в тестовой категории. Фикстура переведена на отслеживаемый файл проекта.
- Следующий реальный прогон обнаружил ссылки меню на `/#vehicle-showcase` при
  пустом тестовом каталоге. Для полного прогона применяется обычный локальный
  `supabase/seed.sql` только в одноразовой базе; ссылки и секция присутствуют.
- GREEN: полный прогон завершился успешно. Это не доказательство готовности
  production-каталога: использовался локальный seed.

## Проверки

- Изолированная БД: 82 pgTAP-проверки прошли; 17 HTTP-проверок и 14 проверок
  захвата прошли, включая две гонки и две независимые выгрузки выпуска.
- Настоящий локальный Next build, crawl и упаковка: 92 маршрута записаны,
  0 ошибок crawl, 182 файла в пакете. Worker: 103337 байт, gzip 23577 байт.
- `node scripts/cloudflare/verify-package-integrity.mjs --package <новый пакет>`:
  `ok: true`.
- `npm run check`: exit 0, 209 файлов тестов прошли, 1 пропущен; 1880 тестов
  прошли, 4 пропущены. Lint, typecheck и check:colors прошли.
- `git diff --check`: exit 0; предупреждения Git касались только LF/CRLF.

Пакет имеет `ready: true` как локально проверенный артефакт, но
`productionReady: false`. Он не публиковался. Публичный Worker-поиск пока
читает живой каталог, а не тот же выпуск, из которого сделаны HTML-страницы;
это следующий барьер согласованности. Также не проверены реальная удалённая
сборка, Cloudflare-маршрутизация и переключение DNS.
