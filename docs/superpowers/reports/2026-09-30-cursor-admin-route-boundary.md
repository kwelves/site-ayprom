# Границы статических файлов админки на локальном workerd

Дата: 2026-09-30. Ветка: `codex/cursor-admin-route-boundary-tests`.
Основа: `4a40a71da4ca152f46f101374230784b50aa41d9`.
Прежняя ветка `codex/cursor-selected-preview-runtime` осталась на `63da2b2a995a6d2f102179d6fe3e7469ab172c6e`.

Проверка идёт против настоящего локального Worker и Static Assets. Это не доказательство маршрутов на удалённом Cloudflare.

## Что проверялось

Учебные страницы лежат в `fixtures/cloudflare-admin-route-boundary`. В оболочке админки есть метка `ADMIN_SHELL_SECRET_MARKER`. Тест без сессии шлёт сырой HTTP-запрос, не давая клиенту заранее переписать адрес, и смотрит, что метка не попала в ответ. Отдельная проверка показывает: если в текст подставить открытый файл, тест падает. Так он ловит утечку, а не только код ответа.

На локальном workerd без сессии:

- `/admin` и `/admin/products` — 302 на `/admin/login`, метки оболочки нет.
- Прямые `/admin/index.html` и `/admin/login.html` — 404, страницы не открываются.
- Вариант регистра `/admin/Index.html` — 302 на вход. `/ADMIN/index.html` — 404.
- Вопрос в адресе не попадает в ответ. Точки и `%2e%2e` для прямого файла дают 404.
- Двойной слеш `/admin//index.html` — 302 на вход.
- Адрес `//admin/index.html` браузерный разбор превращает в другой путь `/index.html`, но сырой запрос сервер принял как есть и ответил 307 на `/admin`. Следующий шаг не открывает оболочку.
- `%2f` в `/admin%2findex.html` не открывает файл: 307 на `/admin`.
- `%69` в имени не открывает оболочку: 302 на вход.
- HEAD и POST не обходят защиту: HEAD/POST `/admin` — 405, для файла `index.html` — 404.
- Обычный `/admin/login` — 200 и страница входа. `/api/health` — 200 и `status: ok`.

Обхода, который отдаёт секретную оболочку без сессии, не найдено. Production-код не менялся.

`npm run check`: exit 0. 1478 тестов прошли, 4 пропущены.

## Что не доказано

Это локальный workerd, не удалённые маршруты и не квота Cloudflare. После проверки файлы по-прежнему можно подменить отдельно. На сервер ничего не отправлялось.
