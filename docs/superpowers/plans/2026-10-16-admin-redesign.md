# Редизайн админки AYPROM

Начат 16 октября 2026, параллельно с этапом G переезда. Ветка `codex/admin-redesign`.

## Источник истины

- Дизайн-система AYPROM v2 «Контрастное стекло»: `C:\Erkin\ayprom-design-system\AYPROM-DESIGN-SYSTEM.md`, макет `preview/aypromos/index.html`, скриншоты `preview/aypromos/screenshots/`. Админка — «рабочее место»: стекло, Geist, светлая сцена и тёмная тема.
- Публичный сайт (витрина) не меняется. Всё новое включается только под `[data-admin-root]`.
- Решения владельца: без жёлтого CAT; название «AYPROM · Админка»; основной экран — ноутбук; функции сохраняются полностью.

## Что не нравится владельцу (исходные жалобы)

1. Блок входа прилип к верху экрана (в SPA-версии обёртка страницы не растягивается по высоте).
2. Форма товара: пять пустых свёрнутых блоков (совместимость, описания, характеристики, фото, SEO), неудобно и «AI-слоп».
3. Нет анимаций; однообразно чёрно-белое с синим; плохие отступы и типографика.
4. Статус «опубликовано / ждёт публикации» неудобный, без анимации.
5. Мелкие фото товаров; нужно увеличение при наведении; неудобные кнопки.

## Этапы

1. **Фундамент.** Семантические токены переводятся из `@theme inline` в `@theme`, чтобы админка могла переопределить их у себя (сцена, стекло трёх плотностей, кромки, тёмная тема); витрина получает те же значения. Новые токены стекла и градиента кнопки. Кривые и длительности движения из раздела 6 дизайн-системы. Кнопки (главная с градиентом, стеклянная, прозрачная, опасная, состояния «сохраняю» и «готово»), поля 38 px, чипы, статусы, переключатель, сегмент с бегунком, диалог, уведомления, заготовки загрузки.
2. **Каркас.** Боковая панель 248/72 px с группами и едущей подложкой активного пункта; верхняя полоса 60 px со стеклом: крошки, поиск товара (Ctrl+K), луна, выход; статус публикации живой карточкой; вход по центру; смена экрана с анимацией.
3. **Товары.** Список: крупные фото с увеличением при наведении, статусы словом и цветом, понятные действия. Форма: две колонки на ноутбуке. Слева: основное (название, адрес, категория, подкатегория, артикул), описание, характеристики, SEO. Справа, прилипая: публикация и наличие, фотографии крупно, совместимость чипами. Все разделы открыты, сверху навигация по разделам. Панель «Сохранить» прилипает снизу.
4. **Остальные экраны** в той же системе: категории и подкатегории, бренды, типы техники, витрина техники, импорт, журнал, пароль, приветствие.
5. **Проверка.** `npm run check`, e2e админки на Cloudflare-сборке (`scripts/e2e/run-admin-cloudflare.mjs`), снимки 1440/834/390 px в светлой и тёмной теме, «уменьшить движение», детектор Impeccable и независимый финальный обзор.

## Ограничения

- Цвет только токенами (`npm run check:colors`), новые токены — в `globals.css` и `docs/design-tokens.md`.
- Без новых крупных зависимостей: Geist и framer-motion уже в проекте.
- Скорость: анимации только `opacity`/`transform`, стекло с размытием только у прилипающих и всплывающих слоёв, не больше двух бесконечных анимаций на экране.
- Локальный просмотр: `node scripts/cloudflare/admin-local-preview.mjs` (локальная Supabase, тестовый пароль), порт 3101.
