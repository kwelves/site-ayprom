# Дизайн-токены

Цвет в приложении задаётся **только** семантическими токенами. Прямые палитровые
классы Tailwind (`bg-blue-600`, `text-slate-600`), утилиты `-white`/`-black` и
захардкоженные значения (`bg-[#084bb9]`) запрещены и отклоняются проверкой
`npm run check:colors` — она входит в `npm run check`, а значит и в CI.

Токены объявлены в одном месте: `src/app/globals.css`, блок `@theme inline`.
Tailwind v4 генерирует из них обычные утилиты (`bg-primary`, `text-danger`,
`border-input`), включая модификаторы прозрачности (`bg-inverse/90`).

## Размер текста

Иерархию задаёт размер, а не только насыщенность: `font-medium`/`font-semibold`
поверх и без того мелкого `text-sm`/`text-xs` читается как «плоско», а не как
акцент. Средний диапазон (`text-base`) — рабочая лошадка, а не пропуск в шкале.

| Класс | Когда использовать |
|---|---|
| `text-2xl` / `text-3xl` | заголовки секций (`SectionHeading`) |
| `text-base` | основной текст: название товара/категории/бренда в карточке, тело страницы |
| `text-sm` | вторичный текст: описание под названием, подписи, лейблы форм |
| `text-xs` | не для текста, который читают — только служебные пометки (счётчики, бейджи) |

`font-medium`/`font-semibold` — для настоящего акцента внутри одного размера
(например, название карточки на фоне её же описания), не как замена размеру.

### Единый hover-border сеток

Цвет постоянного края карточки меняется через `--color-card-edge`, а цвет
движущейся подложки — через `--color-card-hover-highlight`.
Геометрия и движение централизованы в `HoverBorderGrid`: один экземпляр
подложки обслуживает всю сетку, а кликабельные карточки отмечаются
`data-hover-border-item`.

```tsx
<HoverBorderGrid>
  <div className="grid ...">
    <Link data-hover-border-item href="...">...</Link>
  </div>
</HoverBorderGrid>
```

- Оборачивайте всю сетку, а не каждую карточку отдельно.
- Отмечайте только карточку, целиком ведущую по одному адресу. Информационные
  плитки и карточки с несколькими самостоятельными ссылками не отмечаются.
- Не добавляйте отмеченной карточке второй `hover:scale`, подъём, тень или
  смену рамки: движущаяся подложка заменяет прежний hover, а не дополняет его.
- `focus-visible` и `active` остаются на самой карточке — общий эффект отвечает
  только за наведение мыши.

## Тёмные («инверсные») поверхности

Подвал, оверлей на фотографии в Hero, `SectionHeading tone="inverse"`.

| Класс | Значение | Когда использовать |
|---|---|---|
| `bg-inverse` | slate-900 | тёмная подложка, градиенты (`from-inverse/90`) |
| `text-inverse-foreground` | white | заголовки и активный текст на тёмном |
| `text-inverse-foreground-muted` | slate-300 | основной текст на тёмном |
| `text-inverse-foreground-subtle` | slate-400 | подписи и разделители на тёмном |
| `border-inverse-border` | slate-800 | разделители на тёмном |
| `text-inverse-accent` | blue-400 | ссылки и иконки на тёмном |

Обычные `text-muted-foreground` и `text-faint-foreground` на тёмном фоне
использовать нельзя — они рассчитаны на белый фон и не дают контраста.

## Статусы

Один и тот же шаблон из четырёх слотов: текст, заливка, заливка при наведении, рамка.

| Статус | Текст | Заливка | Заливка hover | Рамка |
|---|---|---|---|---|

## Если нужного цвета нет

Не пишите прямой класс — добавьте токен.

1. Проверьте, что задача не решается существующим токеном: почти всё покрывается
   парами «поверхность + текст на ней».
2. Добавьте переменную в `@theme inline` в `src/app/globals.css`, ссылаясь на
   палитру Tailwind (`--color-новый: var(--color-slate-700)`), и назовите её по
   роли, а не по цвету: `input`, `danger-surface`, а не `gray-line`, `red-bg`.
3. Добавьте строку в таблицу выше.
4. По желанию добавьте подсказку «на что менять» в `SUGGESTIONS` в
   `scripts/check-color-tokens.mjs` — она выводится в сообщении об ошибке.

## Исключения из проверки

Список в `scripts/check-color-tokens.mjs` (константа `ALLOWLIST`), каждое — с причиной:

- `src/app/globals.css` — здесь палитра и токены определяются;
- `src/components/home/vehicle-showcase/**` и `VehicleShowcaseSection.tsx` —
  декоративная 3D-сцена: оттенки свечения подобраны под сцену, а не под палитру интерфейса;
- `src/components/home/_archive/**` — архив прошлой версии витрины.

Кроме того, проверка не считает нарушением `rgba` внутри `shadow-[…]` и
`drop-shadow-[…]`: это параметр эффекта, а не цвет палитры.

Список исключений не должен расти без обсуждения.

# Токены движения

Длительности и кривые задаются токенами по тем же правилам, что и цвета:
объявлены один раз в блоке `@theme` в `src/app/globals.css`, оттуда Tailwind
делает утилиты `duration-*` и `ease-*`.

## Кривые

| Токен | Значение | Когда |
|---|---|---|
| `ease-ui` | `cubic-bezier(0.23, 1, 0.32, 1)` | По умолчанию: появление, наведение, любое движение в ответ на действие |
| `ease-ui-in-out` | `cubic-bezier(0.77, 0, 0.175, 1)` | Симметричные состояния, где раскрытие и схлопывание равноправны — высота мобильной панели |

Обе кривые быстро стартуют и мягко тормозят. Кривая с медленным стартом
(`ease-in`) в интерфейсе не используется: движение должно начинаться в момент
нажатия, иначе отклик ощущается запоздалым.

## Длительности

| Токен | Значение | Когда |
|---|---|---|
| `duration-fast` | 150 мс | Цвет, наведение, нажатие, мелкая обратная связь |
| `duration-base` | 200 мс | Появление панелей и выпадающих меню, смена фото |
| `duration-slow` | 280 мс | Изменение высоты, крупные перемещения |
| `duration-reveal` | 420 мс | Появление блока при прокрутке страницы |

Уход всегда короче прихода — обычно на одну ступень: панель приходит за
`duration-slow`, уходит за `duration-base`.

## Готовые анимации

| Токен | Что делает |
|---|---|
| `animate-fade-up` | Появление со смещением снизу вверх |
| `animate-pop-in` | Появление с лёгким увеличением (старт с 0.94) |
| `animate-nudge-down` | Бесконечное покачивание вниз — подсказка «прокрути» |
| `animate-whatsapp-pulse` | Бесконечное расходящееся кольцо — закреплённая кнопка WhatsApp |
| `animate-attention-pulse` | Медленное расходящееся кольцо — иконка блока «Внимание» на странице товара КОМ |

Каскад делается задержками: `[animation-delay:60ms]`, `[animation-delay:120ms]`.

## Правила

- Анимируйте только `opacity`, `translate`, `scale`, `rotate` и цвета. Свойства
  раскладки (`width`, `height`, `top`) заставляют браузер пересчитывать страницу
  каждый кадр — вместо ширины меняйте `scale-x`.
- В Tailwind v4 `scale-*` и `translate-*` пишутся в самостоятельные CSS-свойства
  `scale` и `translate`, а не в `transform`. В списке `transition-[…]` их нужно
  называть прямо; `transition-transform` покрывает все четыре сразу.
- `prefers-reduced-motion` для CSS обрабатывается общим правилом в `globals.css`,
  для framer-motion — через `<MotionConfig reducedMotion="user">`. Отдельная
  проверка в компоненте нужна только там, где анимацией управляет JS вручную.
- Наведение задавайте вариантом `hover:`: в Tailwind v4 он уже завёрнут в
  `@media (hover: hover)`, поэтому эффект не залипает после тапа на телефоне.
  У framer-motion `whileHover` такой защиты нет.

## Framer Motion

Framer не читает CSS-переменные, поэтому те же значения продублированы в
`src/lib/motion.ts` (`DURATION`, `EASE_UI`, `EASE_UI_IN_OUT`), а
`tests/motion-tokens.test.ts` сверяет две копии.

Framer оставлен только там, где CSS не справляется: `AnimatePresence`
(анимация ухода размонтируемого элемента), `whileInView` (появление при
прокрутке), анимация `height: auto`. Всё остальное — классы.

## Исключения

Скрипта-запрета для движения нет: законных исключений слишком много.
Отступление от токенов допустимо, но требует комментария рядом. Сейчас оно одно:

- `src/components/home/vehicle-showcase/**` и `_archive/**` — декоративная
  сцена со своей хореографией и архив прошлой версии витрины.
