# Неизменяемые требования (Non-negotiables)

Зафиксировано Lead Orchestrator напрямую из брифа пользователя — не подлежит пересмотру дизайн-агентами, критиком или Council.

- AYPROM остаётся сайтом-каталогом (не превращается в лендинг/арт-сайт).
- Существующие товары и категории сохраняются.
- Существующие рабочие URL не ломаются (включая `/catalog/category/[slug]/...`, `/catalog/brand/[slug]/...`, `/catalog/vehicle-type/[slug]`, канонический редиректор `/product/[slug]`).
- Контактные сценарии сохраняются (поиск через `/catalog?q=`, кнопки перехода к каталогу/маркам).
- Реальные данные не заменяются mock-данными — источник истины: Supabase через `src/lib/queries/*`, тип `Product`/`ProductListItem` (`src/types/catalog.ts`).
- Фирменная идентичность сохраняется: `--color-primary: #084bb9` (blue-600), `--color-accent: #084bb9` on blue-50, `--color-ring: #4f91f8`. Новые токены — только производные (glow/rgb) от этих значений.
- Логотип не переделывается без прямого требования.
- Не использовать чужие изображения через hotlink (в т.ч. с gidravlikov.ru).
- Не копировать сайты-конкуренты дизайном/кодом/разметкой.
- Mobile — отдельная продуманная композиция, не пропорциональное сжатие desktop.
- Сайт остаётся быстрым — одно фоновое видео на Hero-сцену, без Three.js/WebGL/тяжёлых 3D-библиотек.
- Визуальные эффекты не мешают выбору товара (каталог, поиск, карточка товара — приоритет над декором).
- Доступность и читаемость обязательны (контраст, keyboard nav, focus-visible, aria-label, prefers-reduced-motion).
- SEO-важный контент не должен исчезать из HTML (server-rendered контент остаётся server-rendered).
- Не должно быть hydration errors.
- Сборка Vercel должна проходить на каждом чекпоинте.
- Не проводить полный rewrite без технической необходимости — переиспользовать `ProductCard`, `Button`, query-функции, существующую per-vehicle геометрию `VehicleShowcaseCard`, где это возможно.
- Не менять архитектуру (App Router, Supabase, npm) ради удобства дизайнера.
- Не превращать весь сайт в один тяжёлый анимационный экран.
- Зарезервировать fixed bottom-right угол (z-50+) под будущий WhatsApp-бейдж — пока не реализован в коде, но зафиксирован в `CLAUDE.md`/`PROJECT_BRIEF.md` как обязательный.
- Библиотека анимаций — уже установленный `framer-motion ^12.42.2`, не новый пакет `motion`.
- Package manager — npm (`package-lock.json`), не менять.
