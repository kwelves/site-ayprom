## Рабочий профиль

- Общаться по-русски, понятным владельцу языком: результат, ограничения, следующий шаг.
- План и границы берём из AGENTS.md, PROJECT_BRIEF.md и утверждённых документов
  миграции. ECC дополняет их, а не заменяет новым проектом или новой архитектурой.
- `tdd-workflow`: сначала воспроизводимый провал теста, затем исправление и тот же
  успешный тест. Доказательства сохранять в отчёте; не выдавать наличие теста за его запуск.
- `security-review`: проверять публичные права БД, доступ к черновикам, сессии,
  валидацию входа и отсутствие секретов в ошибках/логах/пакете сайта.
- `verification-loop`: использовать реальные команды проекта и явно различать
  unit, настоящую локальную БД/workerd, браузер и удалённый стенд.

## Команды и среда

Windows / PowerShell, npm / Vitest. `npm test` уже содержит `--maxWorkers=2`:
не добавлять этот флаг второй раз. Целевой запуск: `npx vitest run <test>`.
Общая проверка: `npm run check`; сборка: `npm run build` в допустимом окружении.
SQL проверять pgTAP и настоящим локальным PostgREST; jsdom не заменяет браузер.
После значительного изменения: `git diff --check`, Graphify, локальный checkpoint
только своих файлов. Не выполнять `npm audit fix`/`npm update` просто потому,
что они приведены как пример в ECC. Не выводить найденные секреты при проверках.

## Границы подключения

Настройки моделей, разрешений и существующих MCP не заменялись. Native plugin
содержит отдельный Chrome DevTools MCP; он не считается автоматически проверенным
или настроенным. Для текущей работы использовать уже доступные средства браузера.
SessionStart hook ECC не получал доверия от агента; ручная правка хранилища доверия
запрещена. Автопамять, автоотправка данных, платные сервисы и автоматический deploy
не включались. Любое сетевое изменение выполнять только в границах конкретного
разрешения владельца; установка ECC сама такого разрешения не добавляет.

## Первое применение

Проверка нового SQL выпуска каталога обнаружила, что автоматически сформированный
diff не содержит явных GRANT/REVOKE из исходной схемы. Такой файл ещё не готов к
применению. Необходимо проверить права и поведение на изолированной БД, включая
запрет чтения неопубликованной версии без права именно на эту версию.
